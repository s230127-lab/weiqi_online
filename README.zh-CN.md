# 围棋 Weiqi

以简体中文为默认界面的浏览器围棋遊戲。可在电脑、平板及手機上游玩，支持人機对弈、同机双人对弈，以及面對面对弈。

[简体中文](./README.zh-CN.md) · [English (UK)](./README.en-GB.md) · [English (US)](./README.en-US.md)

## 开始游戏

请打开已部署的 GitHub Pages 網址，或自行部署本项目。

- **项目仓库：** https://github.com/s230127-lab/weiqi_online
- **主要游戏程序：** [index.html](./index.html)
- **KataGo ONNX 模型：** [models/katago.onnx](./models/katago.onnx)
- **Firestore 安全规则：** [firestore.rules](./firestore.rules)

### 自行部署

将整個项目部署到支持靜態網站的主機，並保留 `models/` 文件夹及其模型文件。請透過 HTTP 或 HTTPS 網址打开遊戲，不要直接以 `file://` 打开 `index.html`；浏览器需要由網站伺服器加载模型及其他資源。

## 第一次游玩

第一次按下「開始对弈」时，遊戲會自动显示五步新手導覽，介紹玩法选择、棋盘尺寸、电脑等級、落子方式及对局按鈕。完成或略過后，遊戲會在当前浏览器記住這項設定；之后仍可按遊戲画面上方的「新手導覽」重新閱讀。清除浏览器網站資料后，導覽可能再次出現。

## 游戏功能

- **三種对弈模式：** 人機对弈、双人对弈、面對面对弈。
- **六種电脑等級：** 從簡單的本機策略到 KataGo 及旧版 Leela Zero 浏览器引擎。
- **三種棋盘尺寸：** 9 路、13 路及 19 路。
- **黑白棋色选择：** 人機模式可选择執黑或執白。
- **对局操作：** 悔棋、虚手、认输及新遊戲。
- **计时器：** 可停止或繼續計时；手动停止时會鎖定棋局，不能落子或使用对局操作。KataGo 局面分析期间会自动暂停计时；整盘逐手分析期间计时器会继续运行，并可继续操作棋局。
- **终局计分：** 可手动或自动標記死子，再使用中國规则数子。
- **面對面版面：** 可把平板或筆電放在兩位玩家中間，双方資訊及操作按鈕會朝向各自一側。
- **触控及桌面操作：** 支持滑鼠、触控螢幕及不同尺寸的画面。
- **Kaya 風格 AI 分析：** 使用本機 KataGo ONNX 模型提供 MCTS 局面分析、候選著手、主要變化、整盤逐手分析、胜率估計走勢圖，以及模型支持时的領地熱圖。

## 对弈模式

| 模式 | 說明 |
| --- | --- |
| 人機对弈 | 与电脑对弈，可选择电脑等級及自己使用黑棋或白棋。 |
| 双人对弈 | 兩位玩家輪流使用同一個棋盘。 |
| 面對面对弈 | 将设备平放在兩位玩家中間；黑方坐在设备下方，白方坐在上方。双方各自的資訊与操作按鈕會朝向自己。 |

面對面模式適合共用一台平板或筆電。认输操作需要再次確認，以減少誤觸。

## 电脑等級

| 等級 | 名稱 | 下棋方式 |
| --- | --- | --- |
| Lv 1 | 入門 | 隨機选择合法棋步。 |
| Lv 2 | 初級 | 使用基本戰術判斷，例如提子、叫吃及避免自打吃。 |
| Lv 3 | 中級 | 使用蒙地卡羅模擬評估候選棋步。 |
| Lv 4 | 高級 | 使用更多模擬思考，通常比 Lv 3 花費更長时間。 |
| Lv 5 | KataGo AI | 使用项目内的 ONNX 模型进行本機推論。 |
| Lv 6 | Leela Zero（旧版 WebGL） | 使用 2017 年的浏览器移植版；僅支持 19 路棋盘。 |

Lv 1–5 可选择 9 路、13 路或 19 路棋盘。Lv 6 的旧版 Leela Zero 僅支持 19 路。电脑在浏览器内运算，实际思考时間會因设备效能及棋盘大小而異。

## KataGo AI 与 Kaya 風格分析

KataGo ONNX 模型位於：

```text
models/katago.onnx
```

选择人機模式並使用 **Lv 5**，或在棋局中啟動 AI 分析时，遊戲才會加载模型。其他电脑等級不需要這個模型。

- **首次加载：** 浏览器需要加载約 75 MB 的模型数据，並取得 ONNX Runtime Web 程式庫，因此首次使用需要网络连接。
- **再次使用：** 浏览器會嘗試快取模型；快取仍可用时，之后可能不必重新下載。
- **本機推論：** 模型加载后，棋步推論及分析由你的设备在浏览器内執行，不會把棋局送到遠端 AI 推論 API。
- **局面分析：** 「分析当前局面」會執行 PUCT 蒙地卡羅樹搜索，显示候選著手、搜索访问数、黑方胜率估計、目數估計及主要候選著手的后續變化。
- **搜索量：** 可选择每個局面的搜索访问数。增加访问数通常會增加分析时間及设备負擔。
- **整盤逐手分析：** 可逐手分析棋譜中的局面，對照实际著手与搜索首選，並呈現估計胜率變化及逐手摘要。
- **分析图表及領地熱圖：** 分析過程可显示黑方估計胜率走勢。領地熱圖只有在当前模型確實提供 KataGo ownership 輸出时才可用；没有模型輸出时不會以其他估算冒充。
- **功能範圍：** 这是把 Kaya 的 KataGo ONNX／PUCT 分析概念整合到本项目單頁遊戲，并不是完整的 Kaya 應用程式，也不包含 Kaya 的所有設定及完整分析樹浏览器。

分析中的胜率、目數、候選棋步及逐手評價都是有限搜索量下的模型估計，不是保證結果，也不應視为實戰胜率。

## Leela Zero（Lv 6）

Lv 6 使用 [NTT123/leela-zero 的浏览器版移植](https://github.com/NTT123/leela-zero/tree/565ae3380946546504bb38c67a714b6c70300a23/src/docs)。这是 2017 年的旧版 WebGL／WebAssembly 示範，不是最新 Leela Zero 桌面引擎。

- 首次使用會從固定版本的第三方 CDN 加载引擎程式及神經網路資料。
- 神經網路推論透過浏览器 WebGL 執行；引擎使用 WebAssembly 執行。
- 需要支持 WebGL 的浏览器，且只支持 19 路棋盘。
- 旧版程式或模型可能不適用於部分較新的浏览器或设备。
- 原始程式採 GPL-3.0；请参阅[上游许可文件](https://github.com/NTT123/leela-zero/blob/565ae3380946546504bb38c67a714b6c70300a23/COPYING)。移植版及模型文件的權利聲明以原始项目为準。

## 基本规则

1. 黑方先行，之后双方輪流下一子；每回合可在棋盘任一合法交叉點落子。
2. 相连的同色棋子形成棋块。棋块相邻的空交叉點稱为「氣」；棋块没有任何氣时，便會被提走。
3. 落子后若自己的棋块没有氣，而且没有因此提走對方棋子，該步就是自殺手，不能下。
4. 遊戲禁止全局同形：不能讓棋盘重現之前出現過的局面。
5. 双方连续虚手即進入終局。
6. 終局时，双方確認並標記死子，再进行数子。可逐一点选棋块標記，也可以使用「自动標記死子」；自动判定結果仍建議由双方確認。

### 计分方式

本遊戲採用**中國规则的数子法**，計算棋盘上存活的棋子，以及由該方圍住的空點。

- 13 路及 19 路棋盘：黑方貼 **7.5 子**。
- 9 路棋盘：本遊戲設定黑方貼 **7 子**。

## 操作说明

- **落子：** 點擊或触控棋盘上的交叉點。
- **悔棋：** 按「悔棋」返回之前的局面。
- **虚手：** 按「虚手」跳過這一回合。
- **认输：** 按「认输」结束对局；面對面模式會要求再次確認。
- **数子：** 双方连续虚手后，標記死子並按「数子」計算結果。
- **新遊戲：** 按「新遊戲」重新開始，也可更改模式、棋盘尺寸、棋色及电脑等級。

## 语言、登录与排行榜

遊戲提供繁體中文及英文介面。可以在歡迎頁或遊戲画面上方切換语言；语言选择會保存在当前浏览器。

排行榜使用 Google 登录及 Firebase Authentication／Cloud Firestore。未設定 Firebase 时，遊戲及本機电脑对弈仍可使用，但登录、保存成績与排行榜不會運作。若要启用排行榜：

1. 在 [Firebase Console](https://console.firebase.google.com/) 创建 Firebase 项目，並新增 Web App。
2. 在 **Authentication → Sign-in method** 启用 **Google** 登录。
3. 创建 **Firestore Database**。
4. 将 Web App 配置值（`apiKey`、`authDomain`、`projectId`、`appId`）填入 `index.html` 的 `FIREBASE_CONFIG`。這些是浏览器端公開設定，不是 Admin SDK 私钥；切勿把服务账户私钥放進网页。
5. 在 Firebase Authentication 的 **Authorized domains** 加入实际使用的 GitHub Pages 網域或自訂網域。
6. 将本项目的 [firestore.rules](./firestore.rules) 發佈到 Firestore Rules。

排行榜是休閒用途，不是防作弊競技伺服器。遊戲在浏览器本機运算，伺服器不會重新驗證完整棋譜；正式競技用途應加入伺服器端棋譜驗證。

## 技术信息

- 單頁网页應用程式，主要游戏程序位於 `index.html`。
- 使用 HTML Canvas 繪製棋盘及棋子。
- KataGo 模型格式为 ONNX，由 ONNX Runtime Web 在浏览器内執行。
- Lv 1–6 的对弈及 AI 推論不需要自建 AI 推論 API 或 API 金鑰；Google 登录及排行榜需要設定 Firebase。
- 本機 AI 推論与 Firebase 排行榜是不同功能；使用 AI 对弈不需要登录。
