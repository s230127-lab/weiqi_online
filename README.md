# 圍棋 Weiqi

以繁體中文為預設介面的瀏覽器圍棋遊戲。可在電腦、平板及手機上遊玩，支援人機對弈、同機雙人對弈，以及面對面對弈。

[English (UK)](./README.en-GB.md)

## 開始遊戲

請開啟已部署的 GitHub Pages 網址，或自行部署本專案。

- **專案儲存庫：** https://github.com/s230127-lab/weiqi_online
- **主要遊戲程式：** [index.html](./index.html)
- **KataGo ONNX 模型：** [models/katago.onnx](./models/katago.onnx)
- **Firestore 安全規則：** [firestore.rules](./firestore.rules)

### 自行部署

將整個專案部署到支援靜態網站的主機，並保留 `models/` 資料夾及其模型檔案。請透過 HTTP 或 HTTPS 網址開啟遊戲，不要直接以 `file://` 開啟 `index.html`；瀏覽器需要由網站伺服器載入模型及其他資源。

## 第一次遊玩

第一次按下「開始對弈」時，遊戲會自動顯示五步新手導覽，介紹玩法選擇、棋盤尺寸、電腦等級、落子方式及對局按鈕。完成或略過後，遊戲會在目前瀏覽器記住這項設定；之後仍可按遊戲畫面上方的「新手導覽」重新閱讀。清除瀏覽器網站資料後，導覽可能再次出現。

## 遊戲功能

- **三種對弈模式：** 人機對弈、雙人對弈、面對面對弈。
- **六種電腦等級：** 從簡單的本機策略到 KataGo 及舊版 Leela Zero 瀏覽器引擎。
- **三種棋盤尺寸：** 9 路、13 路及 19 路。
- **黑白棋色選擇：** 人機模式可選擇執黑或執白。
- **對局操作：** 悔棋、虛手、認輸及新遊戲。
- **終局計分：** 可手動或自動標記死子，再使用中國規則數子。
- **面對面版面：** 可把平板或筆電放在兩位玩家中間，雙方資訊及操作按鈕會朝向各自一側。
- **觸控及桌面操作：** 支援滑鼠、觸控螢幕及不同尺寸的畫面。
- **Kaya 風格 AI 分析：** 使用本機 KataGo ONNX 模型提供 MCTS 局面分析、候選著手、主要變化、整盤逐手分析、勝率估計走勢圖，以及模型支援時的領地熱圖。

## 對弈模式

| 模式 | 說明 |
| --- | --- |
| 人機對弈 | 與電腦對弈，可選擇電腦等級及自己使用黑棋或白棋。 |
| 雙人對弈 | 兩位玩家輪流使用同一個棋盤。 |
| 面對面對弈 | 將裝置平放在兩位玩家中間；黑方坐在裝置下方，白方坐在上方。雙方各自的資訊與操作按鈕會朝向自己。 |

面對面模式適合共用一台平板或筆電。認輸操作需要再次確認，以減少誤觸。

## 電腦等級

| 等級 | 名稱 | 下棋方式 |
| --- | --- | --- |
| Lv 1 | 入門 | 隨機選擇合法棋步。 |
| Lv 2 | 初級 | 使用基本戰術判斷，例如提子、叫吃及避免自打吃。 |
| Lv 3 | 中級 | 使用蒙地卡羅模擬評估候選棋步。 |
| Lv 4 | 高級 | 使用更多模擬思考，通常比 Lv 3 花費更長時間。 |
| Lv 5 | KataGo AI | 使用專案內的 ONNX 模型進行本機推論。 |
| Lv 6 | Leela Zero（舊版 WebGL） | 使用 2017 年的瀏覽器移植版；僅支援 19 路棋盤。 |

Lv 1–5 可選擇 9 路、13 路或 19 路棋盤。Lv 6 的舊版 Leela Zero 僅支援 19 路。電腦在瀏覽器內運算，實際思考時間會因裝置效能及棋盤大小而異。

## KataGo AI 與 Kaya 風格分析

KataGo ONNX 模型位於：

```text
models/katago.onnx
```

選擇人機模式並使用 **Lv 5**，或在棋局中啟動 AI 分析時，遊戲才會載入模型。其他電腦等級不需要這個模型。

- **首次載入：** 瀏覽器需要載入約 75 MB 的模型資料，並取得 ONNX Runtime Web 程式庫，因此首次使用需要網路連線。
- **再次使用：** 瀏覽器會嘗試快取模型；快取仍可用時，之後可能不必重新下載。
- **本機推論：** 模型載入後，棋步推論及分析由你的裝置在瀏覽器內執行，不會把棋局送到遠端 AI 推論 API。
- **局面分析：** 「分析目前局面」會執行 PUCT 蒙地卡羅樹搜索，顯示候選著手、搜索訪問數、黑方勝率估計、目數估計及主要候選著手的後續變化。
- **搜索量：** 可選擇每個局面的搜索訪問數。增加訪問數通常會增加分析時間及裝置負擔。
- **整盤逐手分析：** 可逐手分析棋譜中的局面，對照實際著手與搜索首選，並呈現估計勝率變化及逐手摘要。
- **分析圖表及領地熱圖：** 分析過程可顯示黑方估計勝率走勢。領地熱圖只有在目前模型確實提供 KataGo ownership 輸出時才可用；沒有模型輸出時不會以其他估算冒充。
- **功能範圍：** 這是把 Kaya 的 KataGo ONNX／PUCT 分析概念整合到本專案單頁遊戲，並不是完整的 Kaya 應用程式，也不包含 Kaya 的所有設定及完整分析樹瀏覽器。

分析中的勝率、目數、候選棋步及逐手評價都是有限搜索量下的模型估計，不是保證結果，也不應視為實戰勝率。

## Leela Zero（Lv 6）

Lv 6 使用 [NTT123/leela-zero 的瀏覽器版移植](https://github.com/NTT123/leela-zero/tree/565ae3380946546504bb38c67a714b6c70300a23/src/docs)。這是 2017 年的舊版 WebGL／WebAssembly 示範，不是最新 Leela Zero 桌面引擎。

- 首次使用會從固定版本的第三方 CDN 載入引擎程式及神經網路資料。
- 神經網路推論透過瀏覽器 WebGL 執行；引擎使用 WebAssembly 執行。
- 需要支援 WebGL 的瀏覽器，且只支援 19 路棋盤。
- 舊版程式或模型可能不適用於部分較新的瀏覽器或裝置。
- 原始程式採 GPL-3.0；請參閱[上游授權文件](https://github.com/NTT123/leela-zero/blob/565ae3380946546504bb38c67a714b6c70300a23/COPYING)。移植版及模型檔案的權利聲明以原始專案為準。

## 基本規則

1. 黑方先行，之後雙方輪流下一子；每回合可在棋盤任一合法交叉點落子。
2. 相連的同色棋子形成棋塊。棋塊相鄰的空交叉點稱為「氣」；棋塊沒有任何氣時，便會被提走。
3. 落子後若自己的棋塊沒有氣，而且沒有因此提走對方棋子，該步就是自殺手，不能下。
4. 遊戲禁止全局同形：不能讓棋盤重現之前出現過的局面。
5. 雙方連續虛手即進入終局。
6. 終局時，雙方確認並標記死子，再進行數子。可逐一點選棋塊標記，也可以使用「自動標記死子」；自動判定結果仍建議由雙方確認。

### 計分方式

本遊戲採用**中國規則的數子法**，計算棋盤上存活的棋子，以及由該方圍住的空點。

- 13 路及 19 路棋盤：黑方貼 **7.5 子**。
- 9 路棋盤：本遊戲設定黑方貼 **7 子**。

## 操作說明

- **落子：** 點擊或觸控棋盤上的交叉點。
- **悔棋：** 按「悔棋」返回之前的局面。
- **虛手：** 按「虛手」跳過這一回合。
- **認輸：** 按「認輸」結束對局；面對面模式會要求再次確認。
- **數子：** 雙方連續虛手後，標記死子並按「數子」計算結果。
- **新遊戲：** 按「新遊戲」重新開始，也可更改模式、棋盤尺寸、棋色及電腦等級。

## 語言、登入與排行榜

遊戲提供繁體中文及英文介面。可以在歡迎頁或遊戲畫面上方切換語言；語言選擇會保存在目前瀏覽器。

排行榜使用 Google 登入及 Firebase Authentication／Cloud Firestore。未設定 Firebase 時，遊戲及本機電腦對弈仍可使用，但登入、保存成績與排行榜不會運作。若要啟用排行榜：

1. 在 [Firebase Console](https://console.firebase.google.com/) 建立 Firebase 專案，並新增 Web App。
2. 在 **Authentication → Sign-in method** 啟用 **Google** 登入。
3. 建立 **Firestore Database**。
4. 將 Web App 設定值（`apiKey`、`authDomain`、`projectId`、`appId`）填入 `index.html` 的 `FIREBASE_CONFIG`。這些是瀏覽器端公開設定，不是 Admin SDK 私密金鑰；切勿把服務帳戶私密金鑰放進網頁。
5. 在 Firebase Authentication 的 **Authorized domains** 加入實際使用的 GitHub Pages 網域或自訂網域。
6. 將本專案的 [firestore.rules](./firestore.rules) 發佈到 Firestore Rules。

排行榜是休閒用途，不是防作弊競技伺服器。遊戲在瀏覽器本機運算，伺服器不會重新驗證完整棋譜；正式競技用途應加入伺服器端棋譜驗證。

## 技術資訊

- 單頁網頁應用程式，主要遊戲程式位於 `index.html`。
- 使用 HTML Canvas 繪製棋盤及棋子。
- KataGo 模型格式為 ONNX，由 ONNX Runtime Web 在瀏覽器內執行。
- Lv 1–6 的對弈及 AI 推論不需要自建 AI 推論 API 或 API 金鑰；Google 登入及排行榜需要設定 Firebase。
- 本機 AI 推論與 Firebase 排行榜是不同功能；使用 AI 對弈不需要登入。
